Qumulex PCAP Capture Builder

Fill in the capture details, then copy the block and paste it into the server after sudo su. It installs tshark and lftp only if missing, captures until you press Ctrl+C, uploads to the support FTP, and deletes the local file once the upload succeeds.

Capture details

Use the ticket or server ID. Spaces become underscores.
Type the interface name.
FTP password
Blank = lftp asks for it during upload. Remembered in this browser only.

Retrieve the file

      
From FTP (FileZilla, site portaldan.qumulex.dev, user supportftp): open the files folder, drag file.pcap to your PC, then delete it from the server.

    

    

      
What the block does

      
    
        
  1. Stops if you are not root or the interface does not exist (lists the real ones).
    2. 
        
  2. Installs tshark and lftp only if missing. The "non-superusers capture" prompt is answered No automatically.
    3. 
        
  3. Creates the file in /home/qadmin with 777 permissions and starts the capture.
    4. 
        
  4. Ctrl+C stops tshark only. The script keeps going and uploads.
    5. 
        
  5. Uploads to the FTP files/ folder, giving up after about a minute if the server can't reach it.
    6. 
        
  6. Deletes the local pcap only after a successful upload. If the upload fails, the file stays in /home/qadmin.
